# Backend — AI Wardrobe Recommendation System

FastAPI service. Runs against SQLite with zero setup for local dev; swap
`DATABASE_URL` to Postgres when deploying.

## Setup

```bash
python -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env              # then edit JWT_SECRET at minimum
uvicorn app.main:app --reload
```

Server runs at `http://localhost:8000`.
Interactive API docs (auto-generated by FastAPI): `http://localhost:8000/docs`

## Verify it's working

```bash
curl http://localhost:8000/health
curl http://localhost:8000/health/db
```

Both should return `{"status": "ok", ...}`. The second one confirms the
DB connection and table creation both succeeded.

## Project structure

```
app/
├── main.py           # FastAPI app instance, CORS, router wiring, startup hooks
├── config.py         # All environment-driven settings (typed, one source of truth)
├── database.py        # SQLAlchemy engine/session/Base
├── models/            # SQLAlchemy ORM models (DB tables)
├── schemas/            # Pydantic request/response models (API shapes)
├── routers/            # FastAPI route handlers, grouped by feature
└── core/               # Shared logic: security/hashing, JWT, etc. (Phase 1)
```
