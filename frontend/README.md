# Frontend — AI Wardrobe

Not yet scaffolded. To initialize:

```bash
cd frontend
npm create vite@latest . -- --template react
npm install
npm run dev
```

Runs at `http://localhost:5173` by default — matches `FRONTEND_ORIGIN` already
set in the backend's `.env.example` for CORS.

See `../docs/PROJECT_PLAN.md` for what to build here and in what order.
